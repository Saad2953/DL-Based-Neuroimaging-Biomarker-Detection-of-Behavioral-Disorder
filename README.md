# DL-Based Neuroimaging Biomarker Detection of Behavioral Disorder

## Project Overview

This project focuses on developing a Deep Learning-based system for neuroimaging analysis, with Alzheimer's disease selected as the initial research focus, subject to supervisor approval.

The project aims to explore MRI-based neuroimaging data and investigate how Deep Learning techniques can be used for disease-related pattern identification and classification.

## Objectives

- Explore neuroimaging data relevant to Alzheimer's disease.
- Review and analyze suitable MRI datasets.
- Perform data preprocessing and preparation for Deep Learning.
- Develop a suitable Deep Learning-based classification approach.
- Evaluate the model using appropriate performance metrics.
- Investigate relevant imaging patterns that may support disease-related analysis.

## Dataset

Potential datasets include:

- **OASIS:** Open Access Series of Imaging Studies.
- **ADNI:** Alzheimer's Disease Neuroimaging Initiative.

The final dataset will be selected after reviewing data availability, labels, sample size, access conditions, and licensing requirements.
